# Identidad visual obligatoria — Mentoring SST Plus

La única fuente autorizada de la identidad institucional es el archivo **`logo-oficial-movida-sst-plus.png`** del repositorio **`movidasst/principal`**, utilizado en `www.movidasst.com`.

- Archivo de referencia: `https://github.com/movidasst/principal/blob/main/logo-oficial-movida-sst-plus.png`.
- SHA de blob Git verificado: `86d85df7fa4eda6054f898dcc81289a449af096c`.
- Mantener copia binariamente idéntica en este repositorio con el mismo nombre.
- Utilizar ese archivo exacto en encabezado, portada, favicon y manifiesto.
- Las imágenes para compartir deben mostrar el logo original; no usar marcas inventadas ni reimaginadas.
- **Queda prohibido reutilizar** `logo-movida-web.png`, `logo-movida-32.png`, `favicon.ico` o cualquier versión recreada.
- No utilizar imágenes externas de Drive como marca del encabezado.
- No sustituir el logo por un isotipo gráfico M, ilustraciones genéricas o similares.

**Principio:** cuando cambie la identidad, actualizarla desde la fuente oficial del repositorio principal, nunca reconstruirla manualmente.
